# Claxton Law — Character

Source: [claxtonlawgroup.com](https://www.claxtonlawgroup.com/) —
immigration law firm. Reference bundle for **professional services**
positioning where trust and approachability need to coexist.

## The vibe in one line

Webflow-professional but warmed with real people and storytelling.
Reads as *approachable expertise* — never austere-corporate, never
casual-friendly. The design says "you can trust these professionals
AND talk to them like humans."

## Signature moves

- **Light clean canvas** — white/off-white bg dominates. Deep navy
  or muted-blue as the accent color. Subtle warm-orange for
  secondary highlights (never as the primary).
- **Trust-signal density above the fold** — years of experience, cases
  handled, satisfaction %, professional-association logos (AILA, ABA,
  state bar). One row, hairline-separated, no gradients.
- **All-caps overline labels** — category tags in mono caps
  (`ASYLUM`, `NATURALIZATION`, `FAMILY`) at 11.5px, tracked wide.
  Structure signal without decoration.
- **Attorney bios with real portraits** — 5-column carousel of
  attorney headshots. Real photos, real bios (3-4 sentences),
  personal detail included ("first-generation immigrant myself"
  when true). NEVER StyleGAN faces.
- **Multi-language / bilingual signals** — flags, language toggle
  in nav, service copy hint "hablamos español." Signals accessibility
  without being tokenistic.
- **Dual consultation pricing** — 2-column split (online $X /30min vs
  in-person $Y /1hr) with clear CTA per option. Pricing lives
  above-fold-adjacent, not buried.
- **Case-win section** — single-case highlight (client name if
  they've consented, case type, outcome badge). One at a time, not
  a wall of trophies.
- **Standard contact form** — single-column, name/phone/email/message
  + privacy checkbox + submit. Nothing fancy. Reliable > clever.
- **Multi-office footer** — office addresses visible, hours listed,
  phone numbers with real area codes. Physical presence matters for
  professional-service trust.

## What NOT to steal from this reference

- **Multi-color logo** — that's a Claxton-specific choice; keep the
  user's actual brand palette
- **WhatsApp CTA** — only include if the user actually uses WhatsApp
  for client contact (common in some regions, uncommon in others)
- **AILA/ABA logos** — those are attorney-specific; use the user's
  actual professional associations
- **Language switcher** — only if the user actually serves multiple
  language markets

## Tone character (adjective cluster)

Trustworthy. Approachable. Clear. Warm-professional. Never
intimidating. Never chummy. Never over-designed.

## Density profile

Moderate. Center-column bodies stay narrow (max ~640px). Sections
alternate between constrained-text and full-bleed carousels. Not as
airy as Tomorrow's Sunrise, not as data-dense as WRKS Online.

## Reference cluster this belongs to

Webflow professional-services templates (done well), Squarespace law
firm templates, Wealthsimple, Betterment (financial-service trust
signals). Not: Aesop, Framer, Linear.
