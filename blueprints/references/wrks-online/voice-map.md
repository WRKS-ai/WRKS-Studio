# WRKS Online — Voice map

Which users this reference is the RIGHT remix source for.

## Primary fit

- **voice_descriptor**: `bold`, `expert`
- **business_type**: `saas`, `agency`
- **primary_goal**: `book_calls`, `sell_products`, `fix_conversions`
- **site_intent**: `has_site_refresh` (they have a product site to
  redesign) OR `no_site` (they're launching a tech product)

Best for: performance-marketing agencies, B2B SaaS, dev tools,
fintech, growth-marketing consultancies, AI startups (ironic but yes),
CRM companies, analytics platforms.

## Secondary fit (usable with adaptation)

- **voice_descriptor**: `professional` — works if we soften the italic
  accents and lighten the palette one notch
- **business_type**: `service` (professional service) — works for
  higher-end consultancies (McKinsey-adjacent), less for local trades

## Do NOT use for

- `voice_descriptor: warm` — the dark canvas feels cold; use
  Tomorrow's Sunrise instead
- `voice_descriptor: playful` — this reference has zero playfulness;
  use Bill-Fanter or a future playful reference
- `business_type: ecommerce` (fashion, home goods, food) — needs
  imagery-forward not data-forward; use future ecommerce reference
- `business_type: personal_brand` (creator / coach / influencer) —
  use Bill-Fanter instead
- Wellness, nonprofit, community — use Tomorrow's Sunrise
- Law, medical, dentistry — use Claxton Law

## Pair with

Can be paired with:
- **Bill-Fanter** — when user wants dark + bold BUT with more warmth
  from Bill's bento grids. Opus draws structure from WRKS Online +
  card variety from Bill-Fanter.

Never pair with:
- **Tomorrow's Sunrise** — opposite palettes and vibes, remix would
  produce garbage
- **Claxton Law** — different confidence registers

## Signal strength

If the user's brand ingest reveals **dark palette + geometric-sans
typefaces + product screenshots on the current site**, this reference
is the automatic first pick. Weight it 70/30 against secondary
references.
