# WRKS Online — Section inventory (in order)

18 sections between nav and footer. Use as inspiration, not literal
sequence — remix based on user's brand + business_type.

## Above-the-fold

1. **Nav** — sticky horizontal bar, dark. Logo left, product +
   solution dropdowns center, login + primary CTA right. Backdrop-blur
   intensifies on scroll.
2. **Hero** — full-bleed centered on dark canvas. Large headline
   (one clear promise, ~48-64px display), tagline, dual CTAs
   (primary solid white, secondary transparent border). Optional:
   ambient product-mockup peek at the bottom edge.

## Proof + methodology

3. **How-it-works teaser** — headline + 3 responsive-grid product
   screenshots (Instagram, Ads Manager, funnel builder). Positions
   the product as REAL software.
4. **Trust logos** — centered row of 6-8 client logos in a
   horizontal scroll. Monochrome (never full-color grid), 32-40%
   opacity so they read as texture not marketing.
5. **Methodology framework** — 4-column tabs (Build · Launch ·
   Adapt · Scale in the WRKS case; whatever the user's methodology is).
   Each phase expands with detail on click.
6. **Featured case studies** — 4-column card grid. Each card:
   client name + metric highlight ("+312% MQLs in 90 days") + link
   to full case. Restrained — no gradients, no icons.
7. **Stats banner** — full-bleed dark section, centered. Three
   numbers with warm-white text ("500+ businesses served · $20M+
   ad spend managed · $100M+ generated"). Never with dot separators
   between → use middle-dot glyph and only ONCE per banner.

## Deep dives (the heart of the page)

8-11. **Four deep-dive sections** — one per methodology phase.
   Each = asymmetric split. Text-left (headline + description +
   one supporting CTA) + visuals-right (agent-build screenshot,
   deployment tracker, top-performer carousel, budget reallocation
   pie). Alternate split direction between sections for visual
   rhythm. **These are the highest-value sections** — where
   product specificity lives.

## Full-stack + team + content

12. **Full-stack capability grid** — 3×3 grid (or 9-column flex).
    Each cell: icon + product name + one-line description + link.
    Icons: stroke, 20px, 1.7px stroke width. No fills, no duotone.
13. **Money-back / guarantee callout** — centered full-bleed. Big
    typography. Signals risk reversal. One CTA below.
14. **Team section** — split. Photo carousel or grid left, mission
    statement + CTA right. 4 team members max in the visible frame.
15. **Learning hub / content** — 4-column card grid. Each card:
    thumbnail + category label + headline + description + link.

## Close

16. **FAQ accordion** — centered single-column. 6-9 questions
    (VARIED, not the same-6 pattern). Expand-on-click. No decorative
    icons.
17. **Final CTA banner** — centered full-bleed. Headline ("Ready to
    scale?" or the user's equivalent, no clichés) + subtext + dual
    CTAs (call + case studies).
18. **Footer** — multi-column (5 cols). Links grouped by Products /
    Company / Solutions. Contact email visible. Social row.
    Copyright with CURRENT year.

## Adaptation rules

When remixing for a smaller business (not an agency with 9 products):

- Drop the 4-column methodology tabs (section 5) if the user has no
  named framework
- Drop the deep-dive sections down from 4 → 2 (Build + Launch, or
  the user's two most important phases)
- Drop the full-stack grid (section 12) — that's for multi-product
  offerings only
- Keep: hero, trust logos, ONE deep dive, stats banner, team, FAQ,
  final CTA. Minimum 10 sections for the confident-agency feel.

When remixing for solo consultants (no team, no case studies yet):

- Drop team section (14) — replace with about-founder split
- Drop case studies (6) — replace with results-language testimonials
- Drop stats banner (7) — most solo consultants have no numbers to
  brag about. Replace with a quiet proof section (client names +
  outcomes).
