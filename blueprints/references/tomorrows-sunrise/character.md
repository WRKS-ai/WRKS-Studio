# Tomorrow's Sunrise — Character

Source: [tomorrowssunrise.com](https://www.tomorrowssunrise.com/) —
grief/loss/family community. Reference bundle for **warm, light,
emotionally-literate community + wellness + nonprofit** positioning.

## The vibe in one line

Aesop × Basecamp hybrid. Intimate, image-led, emotionally-literate.
The design gets out of the way of the emotion — generous whitespace,
soft-focus nature imagery, and long-form prose that respects the
reader's time. Reads as *compassionate-professional* — never
saccharine, never clinical.

## Signature moves

- **Warm cream canvas** — off-white/bone bg dominates. Never pure
  white. Deep charcoal ink on top.
- **Soft-focus nature imagery** — blurred florals, sunrise/sunset
  skies, foliage. Photography, not illustration. Never sharp
  product shots.
- **Numbered pillars** — sections labeled `:01`, `:02`, `:03`, `:04`
  using tabular mono numerals. Structure without ceremony.
- **Long-form testimonials** — 300-500 words per testimonial,
  expandable via "Read Full Testimonial" modal. Respects individual
  stories rather than trimming to a sentence.
- **Alternating image-text pairs** — feature spotlights alternate
  image-left / image-right. Visual variety without disruption.
- **Emotional headline phrasing** — "You don't have to do this
  alone." Directly addresses the reader's state, not the product's
  features.
- **Generous vertical rhythm** — 100-120px between sections. Sections
  breathe. Never cramped.
- **Warm gradient testimonial backgrounds** — peach → beige → light
  gray on quote cards. The ONE place gradient earns its keep.
- **Zero decoration** — no logo marks, no icons, no orbs, no
  decorative geometry. Typography and photography do all the work.

## What NOT to steal from this reference

- **Cookie/privacy banner as modal overlay** — that's a compliance
  chore, not a design pattern. Skip.
- **Membership pricing display** — three-tier with big prices only if
  the user is actually selling. Otherwise drop.
- **Nature imagery as default** — only use if the user's brand fits.
  A gym website should NOT get sunrise photos; use appropriate
  imagery (studio interiors, portraits).

## Tone character (adjective cluster)

Warm. Quiet. Editorial. Intimate. Human. Never brand-y. Never salesy.
Never rushed.

## Density profile

Very airy. Whitespace does the design work. Long-form prose sits
comfortably in the frame. Reader is trusted to scroll and stay.

## Reference cluster this belongs to

Aesop (warm editorial retail), Kinfolk (magazine restraint), Basecamp
(community warmth), older Notion.com (before their SaaS refresh).
Not: Framer, Linear, WRKS Online.
