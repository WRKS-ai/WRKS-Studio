# Tomorrow's Sunrise — Voice map

Which users this reference is the RIGHT remix source for.

## Primary fit

- **voice_descriptor**: `warm`, `quiet`
- **business_type**: `personal_brand`, `service` (wellness/coaching/therapy)
- **primary_goal**: `build_audience`, `capture_leads`, `book_calls`
- **site_intent**: any

Best for: yoga studios, therapists, life coaches, wellness
practitioners, meditation apps, grief communities, mental-health
services, group coaching programs, mindfulness apps, nonprofits
(especially cause-driven), spiritual/religious communities, doulas +
midwives, family services, mom communities, book clubs, subscription
communities of any warm-emotional type.

## Secondary fit (usable with adaptation)

- **voice_descriptor**: `expert` — works if the user's expertise is
  in a warm domain (family therapist, wellness researcher, editor at
  a lit journal). Doesn't work for tech expertise.
- **business_type**: `agency` (creative agency, brand studio) —
  works for design/brand agencies that lean editorial/craft-forward.
  Doesn't work for performance-marketing agencies (use WRKS Online).

## Do NOT use for

- `voice_descriptor: bold` — the whole aesthetic is deliberately
  quiet; bold voices will feel muzzled
- `voice_descriptor: playful` — too somber for playful brands; use
  Bill-Fanter or future playful reference
- `voice_descriptor: professional` (in the corporate sense) — reads
  as "small business" and clashes with professional expectations
- `business_type: saas` (any tech product) — nature imagery clashes
  with software; use WRKS Online
- `business_type: ecommerce` (unless it's editorial retail like
  Aesop / small-batch skincare) — needs product-imagery grid, not
  photography backgrounds
- Law, medical, dentistry — too soft for legal/medical trust
  signals; use Claxton Law

## Pair with

Can be paired with:
- **Claxton Law** — when user is a warm-but-professional practitioner
  (family therapist, wellness clinic, holistic doctor). Draws
  emotional warmth from Tomorrow's Sunrise + professional trust
  signals from Claxton Law.

Never pair with:
- **WRKS Online** — opposite vibes; remix would produce garbage
- **Bill-Fanter** — bento grids and dark canvas clash with the
  warm-cream aesthetic

## Signal strength

If the user's brand ingest reveals **cream/warm palette + serif
display + testimonial-heavy current site + community language in
copy**, this reference is the automatic first pick. Weight it 80/20
against secondary references.
