# Personal-Brand (Bill-Fanter) — Character

Source: [billfanter.com](https://www.billfanter.com) — creator +
masterclass + community. Reference bundle for **creator, coach,
course-seller, personal-brand-with-a-product** positioning.

## The vibe in one line

Dark stage where the creator is the star. Confident, bento-heavy,
video-forward. The design is a spotlight — real photography of the
founder, real screenshots of their product, real testimonials in
real reviews. Reads as *established creator with something worth
selling*.

## Signature moves

- **Dark canvas throughout** — deep charcoal bg, warm cream ink,
  brand accent used sparingly on CTAs + status. Never light-first
  for this reference.
- **Portrait-split hero** — copy on left with clear promise + dual
  CTA, big portrait photo of the creator on the right, bleeding
  to the edge. Trust row (star rating + student count) inline
  with the copy.
- **6-tile mega bento** — mixed-size grid immediately after hero.
  Image tiles, gradient tiles, testimonial tiles alternating. This
  is where the site's rhythm gets set.
- **Video reels + social screenshots** — 3 vertical video reels
  top + a LinkedIn/Twitter screenshot masonry below. Real content
  from the creator's socials, not stock.
- **Split media + copy sections** — video-embed left, quote + photo
  bento right (or reversed). Media does the heavy lift, copy
  reinforces.
- **Founder story section** — long-form (5 paragraphs) with a
  large portrait. Photo left, story right. Ends the page as the
  human hook.
- **Named methodology or waitlist / list-magnet section** — one
  dedicated section for the lead capture, styled as a compact
  form + preview image.
- **Community section** — Discord/Slack/Circle screenshot with
  numbered benefits listed alongside. "Here's what happens
  inside."

## What NOT to steal from this reference

- **GridDistortion CTA background** — that's a specific WebGL
  effect from the Bill-Fanter build. Skip in most remixes — it's
  a "look at me" flourish that only works when the creator has
  the personality to back it.
- **The exact bento tile shapes** — those are Bill-specific
  content. Remix with the user's actual content types.
- **Numbered pillars** — Tomorrow's Sunrise uses `:01` labels;
  Bill uses a different structure. Don't cross-borrow this.

## Tone character (adjective cluster)

Confident. Personal. Warm-inside-dark. Product-forward. Never
corporate. Never austere. Never sparse.

## Density profile

Dense. Bento grids, video reels, and long testimonial walls pack
the frame. Whitespace between sections is standard (100-120px)
but INSIDE sections the visual density is high. Feels like a
magazine spread.

## Reference cluster this belongs to

Bill Fanter, David Perell, Jay Clouse, Justin Welsh landing (older),
Ali Abdaal course sales pages. Not: Aesop, Linear, professional
services templates.

## Deep-spec files

Unlike the other reference bundles, personal-brand has a deep spec
in `home.md` + `sections/*.md` (11 files) that documents every
section's exact CSS, typography, and content elements. When the
router picks personal-brand as PRIMARY, the generation pipeline
can optionally load the deep spec for maximum fidelity. When
picked as SECONDARY, only this character.md + sections.md are
loaded.
